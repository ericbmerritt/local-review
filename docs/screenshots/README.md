# Screenshot recorder

The two hero GIFs embedded in the workspace README are generated by
[`vhs`](https://github.com/charmbracelet/vhs) from the `.tape` files in this
directory. Re-record them after any visible TUI change.

`vhs` and `ttyd` live in the Nix dev shell. Build current binaries first so the
screenshots reflect the working tree, then run vhs:

```sh
cargo build --release -p jjr -p ggr
nix develop --command vhs docs/screenshots/jjr.tape
nix develop --command vhs docs/screenshots/ggr.tape
```

`jjr.tape` bootstraps a throwaway demo stack at `/tmp/jjr-demo` via
[`setup-jjr-demo.sh`](setup-jjr-demo.sh) (mirrors the retry-policy example from
`specs/jjr-tui-design.md` so the screenshot matches the docs).

`ggr.tape` targets PR #28 in this repo; auto-detect resolves it from the local
git remote. `gh` must be authenticated against github.com.
